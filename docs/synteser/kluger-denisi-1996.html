Finding

  1. Genomsnitt d ≈ 0,41 — men över ⅓ av interventionerna sänkte prestation.
  2. FIT: feedback flyttar uppmärksamhet i hierarki: task learning → task motivation → meta-task/self. Effekten minskar ju närmare self.
  3. Normativ jämförelse, ego-beröm, hot mot självkänsla → uppmärksamhet bort från uppgiften.
  4. Feedback är data, inte automatisk förbättring (citattraditionen i artikeln).
  5. Underbygger senare Hattie/Timperley-varning om self-nivå.

Bedömning mot kunskapsbankens frågor

(1) Vad är optimalt lärande?

Optimalt = feedback som håller kognitiv energi på uppgiften och strategin. Person-/statusfeedback konkurrerar med encoding.

(2) Hur i en verklighet med AI/skärmar (svensk skola)?

GenAI-skada kan ske via FIT-kanalen: chatbots som berömmer, jämför, eller ger “du är smart”-språk; dashboards med ranking; AI som gör elevens self till fokus. Hjälp: task-fokuserad, icke-normativ, hint-baserad feedback. Skada: ego-feedback + svar-på-bricka (kombinerar FIT med Bastani-crutch).

Relevans / Höjer det lärandet?

Villkorligt. Starkaste belägget för att dålig feedback aktivt skadar — centralt när GenAI massproducerar feedback.
