Finding

Sex strategier: spaced practice, interleaving, retrieval practice, elaboration, concrete examples, dual coding.

  1. Spacing + retrieval = kärna; interleaving stödjer diskriminering (särskilt matematik/visuella kategorier).
  2. Dual coding = komplementära koder (≠ learning styles); varning för overload/seductive details (→ CLT-001–003, ATTN-004).
  3. Concrete examples hjälper abstrakt transfer om flera, strukturrelevanta exempel används.
  4. Gap: strategierna saknas i många lärarutbildningsböcker trots evidens.

Mechanism

Sex evidensbaserade strategier (bl.a. spacing, retrieval, interleaving) operationaliserar desirable difficulties i klassrum.

Limits

Tutorial, inte ny meta; vissa strategier (elaboration) har tunnare klassrumsevidens.

This claim dies if …

Meta där retrieval/spacing/interleaving förlorar mot reread/massed under ekologisk klassrumstid med delayed closed-book.

Swedish implication

Start retrieval/spacing/interleaving i planering; measure delayed closed-book, inte bara lektionstest.
