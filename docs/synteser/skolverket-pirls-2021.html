Finding

  1. Sverige 544 poäng (−12 vs 2016); fortfarande +17 över EU/OECD-genomsnitt (som också föll).
  2. Spridningen störst sedan 2001: lågpresterande ökar; högpresterande stabila (nära 2001-topp).
  3. SES och skola avgör: resurssvaga + skolor med låg hemresursgrad står för tappet; resursstarka oförändrade. SES-gap större än övriga Norden.
  4. Elever som inte alltid talar svenska hemma försämrades; alltid-svenska oförändrade.
  5. Flickor > pojkar; gap oförändrat sedan 2016.
  6. Digitalt genomfört prov 2021 (pandemikontext).

Mechanism

Svensk myndighetsbild beskriver nivåer/praktiker — mekanism för lärande måste härledas från underliggande studier, inte från surveyn ensam.

Limits

  • En mätpunkt under/efter pandemi.
  • Ej kausal skärmstudie.
  • Jämförelser EU/OECD-genomsnitt beror på deltagarset.

This claim dies if …

Ny representativ svensk mätning som vänder rapportens nivå-/gapbild och visar att rekommenderad praktik saknar samband med closed-book-utfall.

Swedish implication

Measure rapportens indikatorer lokalt; start åtgärd kopplad till closed-book-kunskap, inte bara tillgång.
