Syntes: Shute (2007/2008) — Focus on Formative Feedback (FB-005)

Källa: Shute, V. J. (2007). Focus on Formative Feedback. ETS RR-07-11; journal: RER 2008, 78(1), 153–189. https://doi.org/10.3102/0034654307313795
Original: 01-originaldokument/shute-2008-formative-feedback/ (ETS OA)
Åldersrelevans: övergripande
Evidensstyrka: hög som designkatalog (syntetiserar Kluger, Bangert-Drowns, Narciss, Mason & Bruning m.fl.).

Fynd

  1. Formativ feedback = information avsedd att modifiera tänkande/beteende för bättre lärande; bör vara specifik, stödjande, trovärdig, i rätt tid.
  2. Typer längs komplexitet: KR → KCR → try-again → error-flagging → elaborated (hints, bugs, informative tutoring).
  3. Guidelines: fokusera task (inte learner); elaborera i hanterbara bitar; undvik normativ jämförelse och betyg-som-äter-kommentar; sparsamt beröm; avbryt inte aktiv problemlösning.
  4. Timing × svårighet/elevnivå: omedelbar ofta bättre för svåra uppgifter/lågt presterande; fördröjd kan stödja transfer.
  5. Scaffolding: mer direktiv tidigt, mer facilitativ senare.

Bedömning mot kunskapsbankens frågor

(1) Vad är optimalt lärande?

Optimalt = feedback som minskar gapet till mål utan att öka cognitive load eller ego-hot — scaffolding som fasas ut.

(2) Hur i en verklighet med AI/skärmar (svensk skola)?

Shutes tabeller är praktisk prompt-/produktchecklista för GenAI: undvik långa essay-kommentarer som ignoreras; ge stegvisa hints utan facit först; ingen ranking; ingen avbrott mid-struggle. Hjälp: skalbar KR/KCR + hints. Skada: verbose self-praise, facit före försök (presearch), interruptive chat under djuparbete.

Begränsningar

  • Narrativ review (ej ny meta); ETS ≠ identisk med journal men kärnan densamma.
  • Före GenAI — principerna överförs väl.

Relevans / Höjer det lärandet?

Ja som designnorm. Bästa “do/don’t”-listan för både lärare och GenAI-verktyg.
