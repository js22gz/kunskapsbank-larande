Finding

  1. Kognitiv/neuro-evidens lutar mot handskrift; sociokulturell mot digitalt (olika design).
  2. Forskningsläget motiverar inte att ersätta penna med tangentbord för nybörjare.
  3. Metodproblem gör starka kausalpåståenden för digitalt-first svaga.

Mechanism

Skrivutveckling gynnas av explicit undervisning i handstil/process; medium är sekundärt till undervisningsdesign.

Limits

Äldre än GenAI; få RCT; Elsevier-paywall.

This claim dies if …

Meta där tidig skrivundervisning utan handstil/fluency-komponent matchar explicit handskriftsundervisning på composition outcomes.

Swedish implication

Start explicit handstil/fluency i tidiga år; measure composition efter undervisning.
