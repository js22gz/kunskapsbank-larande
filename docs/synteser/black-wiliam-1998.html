Finding

  1. Formativ bedömning = bedömning som används för att anpassa undervisning medan lärandet pågår (inte bara betyg i efterhand).
  2. Innovationer som stärker frekvent feedback om lärande ger betydande lärandelyft; i Inside the Black Box anges typiska ES 0,4–0,7 (större än de flesta utbildningsinterventioner).
  3. Lågpresterande gynnas ofta mer → minskat spann samtidigt som genomsnittet höjs.
  4. Nyckelpraktiker: tydliga mål/kriterier, rik frågeställning, feedback som leder till handling, kamrat-/självbedömning, undvik att betyg “äter upp” kommentarer.
  5. Klassrummet är “svarta lådan” i systemreform — inputs utan stöd till formativ praktik räcker inte.

Bedömning mot kunskapsbankens frågor

(1) Vad är optimalt lärande?

Optimalt lärande kräver kontinuerlig evidens om elevens tänkande som styr nästa undervisningsdrag. Summativ poäng utan formativ användning höjer inte lärandet.

(2) Hur i en verklighet med AI/skärmar (svensk skola)?

GenAI kan öka volymen feedback (hjälp för tidspressade lärare) men riskerar att bli summativ disguise — korrekthetspoäng, generiska kommentarer, lösningar utan elevarbete. Formativ logik kräver att AI-output används för att ändra undervisning/elevstrategi, och att bedömning av lärande sker utan genväg (jfr AI-003). Hybrid: AI för snabb task-feedback + lärare för process/SRL och relationskontext (jfr Kaliisa FB-006).

Relevans / Höjer det lärandet?

Ja för formativ praktik som system. GenAI höjer lärandet bara om den förstärker — inte ersätter — den formativa cykeln.
