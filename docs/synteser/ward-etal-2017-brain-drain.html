Finding

Blotta närvaron av den egna smartphonen (desk > pocket > other room) sänker tillgänglig kognitiv kapacitet även utan användning; kostnaden störst vid hög beroendegrad. Comparator: telefon i annat rum.

Replikationsstatus: labb-HE; svensk 1:1-klassrumsreplikation = lucka, inte finding. Använd som mekanismhypotes för “off body”, inte som bevisat betygslyft.

Mechanism

Telefonens saliens binder begränsade WM-resurser (brain drain) utan medveten tanke på enheten.

Limits

Lab, korta uppgifter, HE; mäter WMC/fluid IQ — inte PISA/merit. Ej svensk skolreplikation.

This claim dies if …

Preregistrerad svensk högstadie-/gymnasiereplikation med 1:1 visar nolleffekt av fysisk separation vs “tyst i fickan” på WM och closed-book encoding under lektion.

Swedish implication

Start device off body vid deep work (inte bara tyst läge); measure separation vs pocket som lokal A/B — behandla klassrumsreplikation som lucka.
