Finding

  1. På många skolor används digitala verktyg inte medvetet ämnesdidaktiskt i matte/teknik (t.ex. 16/27 i granskningens bedömning).
  2. Brist på gemensam pedagogisk idé / styrning från rektor och huvudman; IT-inköp utan uppföljning av lärandeeffekt.
  3. Teknisk support finns oftare än IT-pedagogiskt stöd.
  4. När det fungerar: kontinuerlig, motiverad användning kopplad till kursplanemål och elevbehov.
  5. Slutsats: tillgång ≠ kvalitet; huvudmän/rektorer måste leda hur verktyg ska höja kunskapsutveckling.

Mechanism

Svensk myndighetsbild beskriver nivåer/praktiker — mekanism för lärande måste härledas från underliggande studier, inte från surveyn ensam.

Limits

  • 2019 (före pandemi/AI-våg); urval ej representativt nationellt.
  • Fokus matte/teknik, inte svenska/läsning.
  • Kvalitetsgranskning, inte effektstudie.

This claim dies if …

Ny representativ svensk mätning som vänder rapportens nivå-/gapbild och visar att rekommenderad praktik saknar samband med closed-book-utfall.

Swedish implication

Measure rapportens indikatorer lokalt; start åtgärd kopplad till closed-book-kunskap, inte bara tillgång.
