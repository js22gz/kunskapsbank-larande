Finding

  1. Totaleffekt d ≈ 0,54 (95 % CI 0,49–0,59) — utbildningsmässigt stor enligt Lipsey-normer; “måttlig–stor” på Cohens skala.
  2. Ämnesvisa estimat: läsning ≈0,51; matte ≈0,55; språk ≈0,54; stavning ≈0,66; single-subject ≈0,83.
  3. Effekter positiva och signifikanta över delområden; publikations-/metod-/stickprovskaraktäristika förklarade inte systematiskt skillnader.
  4. Liten nedgång vid maintenance; mer exponering → större akademiska effekter. Storlek i nivå med SES-prestationsgap.

Mechanism

Mekanism: en mening tilläggs vid revision — undvik author-voice utan konkurrerande mekanism.

Limits

Fokus på Engelmann-traditionens DI-program; generalisering till all “explicit teaching” kräver Rosenshine/CLT. Amerikansk kontext; implementationskvalitet varierar.

This claim dies if …

This claim dies if: motstridig closed-book-evidens i relevant population publiceras och överlever peer review.

Swedish implication

Swedish implication: measure closed-book och distraktionsfri tid — verbmening fylls per källa.

Bedömning mot kunskapsbankens frågor

(1) Vad är optimalt lärande?

Strukturerade, explicit sekvenserade DI-curricula ger robusta, hållbara vinster — evidensbas för “kunskapsrik + explicit” snarare än lös aktivitetsundervisning.

(2) Hur i AI/skärm-verklighet (svensk skola)?

DI ≠ “drill and kill på skärm”. Poängen är klar undervisningssekvens, check for understanding, hög success rate (Rosenshine). Digitala plattformar som hoppar över modellering/övning eller låter GenAI göra stegen underminerar just det som ger d≈0,5. Svensk tillämpning: import principerna (explicit, scaffold, mastery), inte nödvändigtvis US-programvarumärken.

Relevans / Höjer det lärandet?

Ja — bland de starkaste kvantitativa beläggen för explicit, programmatisk undervisning i banken.
