Metadata

  • ID: MEM-003
  • Tier: quasi/DiD
  • N / design: longitudinell korrelationsstudie (6 år)
  • Population: grundskola-låg → mellan (5 år → 11 år)
  • Subject: Investigating the predictive roles of working memory and IQ in academic attainment

Finding

  1. WM vid 5 år var den starkaste prediktorn för literacy och numeracy sex år senare.
  2. IQ bidrog, men mindre unik varians — WM är inte bara proxy för IQ.
  3. Implikation: tidig identifiering av låg WM kan vägleda stöd innan skolsvårigheter cementeras.
  4. Intervention bör (enligt författarna) rikta lärandeprocesser som beror på WM — i linje med Gathercole lastreducering snarare än IQ-testfokus.

Mechanism

Arbetsminnesbegränsningar styr hur mycket instruktion/elever kan hålla aktivt; träning ger oftast near-transfer, sällan far-transfer.

Limits

  • UK-urval, måttlig n.
  • Prediktion ≠ att träna WM höjer betyg (se MEM-005).
  • Inte svensk normdata.

This claim dies if …

Preregistrerad meta där WM-träning ger robust far-transfer till skolämnen som överlever placebo och delayed test.

Swedish implication

Stop köpa WM-träning för far-transfer; start anpassa instruktion till WM-belastning.
