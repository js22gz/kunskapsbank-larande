Åldersrelevans: övergripande (explicit K–12 + HE + lärare)
Evidensstyrka: låg–medel som empiri (position paper); hög som tidig konsensusram från TUM/LMU-forskare.

Fynd

  1. LLM:er “are here to stay” — förbud är inte hållbar huvudstrategi.
  2. Möjligheter: personalisering, innehållsgenerering, feedback, stöd till lärare (planering, bedömning), språkutveckling.
  3. Krav: AI-litteracitet hos elev och lärare; kritisk tänkande + fact-checking i pedagogiken; mänsklig översikt.
  4. Risker: bias, brittleness/hallucination, missbruk, integritet — kan vändas till lärtillfällen om de hanteras medvetet.
  5. Senare Kasneci-kommunikation (TUM 2026): varnar för deskilling, skill skipping och cognitive offloading om offentliga AI-verktyg används utan pedagogisk design.

Begränsningar

  • Inte RCT/meta; normativa rekommendationer.
  • Tidig 2023 — tekniken har rört sig, men principerna håller.

Implikation: Höjer det lärandet?

Bara om skolan styr designen. Kasneci förstärker ledfråga (2): i svensk skola behövs pedagogiskt ledade Educational Technologies + åldersanpassad AI-litteracitet — inte fri ChatGPT som genväg. Koppla till Bastani/Strömberg för empiri om skada utan guardrails.
