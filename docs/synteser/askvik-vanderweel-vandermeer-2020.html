Finding

  1. Handskrift (digital pen): theta-ERS i parietal/central — mönster kopplat till encoding/minne.
  2. Rita: liknande + viss alpha/beta-desynkronisering.
  3. Tangentbord: annorlunda mönster; läranderelation oklar enligt författarna.
  4. Samma riktning hos 12-åringar, svagare — argument för tidig handskrifts-/teckningsexponering.

Mechanism

Handskrift aktiverar rikare sensomotoriska nätverk än typing i EEG-mätning — föreslagen encodingväg för bokstäver/ord.

Limits

Liten N; labbuppgift; neural korrelat ≠ skolbetyg.

This claim dies if …

Preregistrerad replikering där tangentbord ≥ penna på conceptual/closed-book-utfall i samma population när anteckningsinstruktion hålls konstant.

Swedish implication

Start penna när conceptual encoding är målet; measure retention, inte bara anteckningsvolym.
