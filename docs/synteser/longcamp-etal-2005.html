Finding

  1. Tre veckors träning: kopiera bokstäver för hand vs på tangentbord.
  2. Hos äldre förskolebarn: bättre bokstavsigenkänning efter handskrift (omedelbart + 1 vecka).
  3. Mekanism (2008 OA): handmotoriska minnesspår återaktiveras vid visuell igenkänning (Broca, IPL); typingens pegrörelse bär ingen forminformation.
  4. Policyimplikation redan 2005/2008: tidig datoranvändning i bokstavsinlärning kan påverka hur barn ser skriftspråk.

Mechanism

Writing practice bygger motoriska minnesspår som återaktiveras vid visuell letter recognition — typing saknar samma forminformation.

Limits

Fulltext ej OA här; effekt åldersberoende; igenkänning ≠ läsförståelse.

This claim dies if …

Preregistrerad replikering där tangentbord ≥ penna på conceptual/closed-book-utfall i samma population när anteckningsinstruktion hålls konstant.

Swedish implication

Start penna när conceptual encoding är målet; measure retention, inte bara anteckningsvolym.
