Finding

  1. Feedback = information från en agent om prestation/förståelse; syfte = minska gapet mellan nuvarande och önskad status.
  2. Tre frågor: Where am I going? (feed-up), How am I going? (feed-back), Where to next? (feed-forward).
  3. Fyra nivåer: task, process, self-regulation, self (beröm/person). Task/process/SRL effektiva; self-nivå (praise) minst effektiv / kan störa.
  4. Syntes: genomsnittlig feedback-effekt d ≈ 0,79 (topp 5–10 bland skolpåverkansfaktorer i Visible Learning) — men stor heterogenitet; cues/reinforcement höga; praise/rewards/punishment låga.
  5. Timing, valens och medium ger inkonsistenta resultat; informationsvärdet avgör.

Mechanism

Feedback som svarar where to next / process/task höjer lärande mer än ego-feedback; timing och specificitet styr nyttan.

Limits

  • Meta-syntes (inte primärstudie-meta); d=0,79 överskattar enligt Wisniewski (FB-003: d=0,48).
  • Officiell Sage-PDF bakom paywall (spegling sparad).

This claim dies if …

Meta där generisk/ego-feedback systematiskt slår uppgifts-/processfeedback på delayed learning i K–12.

Swedish implication

Start uppgifts-/processfeedback; stop enbart betyg/ego-kommentarer utan nästa steg.
