Finding

  1. Storage strength vs retrieval strength: lätt prestation nu ≠ stark LTM senare.
  2. Önskvärda svårigheter som triggar djupare encoding/retrieval: spacing (spridd övning), interleaving, variation, testing/generation istället för om-läsning.
  3. Undesirable om eleven saknar förkunskap/färdighet att lyckas — då blir “svårighet” bara hinder (kritiskt i låg-WM-klassrum, jfr MEM-001).
  4. Elever/lärare misstolkar ofta snabb flyt under lektion som lärande (illusions of competence).
  5. Självreglerat lärande: svårt att få elever att välja svårigheter eftersom kortsiktig prestation sjunker.

Mechanism

Arbetsminnesbegränsningar styr hur mycket instruktion/elever kan hålla aktivt; träning ger oftast near-transfer, sällan far-transfer.

Limits

  • 2020-texten är commentary; evidensen ligger i underliggande empiri.
  • Överdosering av svårighet skadar låg-WM/elever utan schema.

This claim dies if …

Preregistrerad meta där WM-träning ger robust far-transfer till skolämnen som överlever placebo och delayed test.

Swedish implication

Stop köpa WM-träning för far-transfer; start anpassa instruktion till WM-belastning.
