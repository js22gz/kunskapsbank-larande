Praktik — stop / start / measure

Praktik — stop / start / measure

Stegvisa handlingar. Inte policyetiketter. Mät distraktionsfri tid och closed-book, inte om ni “har mobilförbud”.

Chiron (kurator) + Jonatan Skäryd (redaktör) · 2026-09-07

F–3

Handling
Stop Keyboard-first för bokstavsinlärning; GenAI som skriver elevens text; skärm som default för linjär nybörjarläsning.
Start Explicit handskriftsundervisning (läslighet + flyt); phonics där behov finns; digital pen endast som stöd — inte ersättning (WRITE-004, HAND-006/007, SE-002).
Measure Bokstavskännedom/avkodning closed-book; handstil i åk 1-bedömning; tid med enhet ur synfält vid encoding.

Åk 4–6

Handling
Stop Oreglerad 1:1 under genomgång; färdiga GenAI-lösningar under övning; anta att “tyst i fickan” är gratis.
Start Hybrid: penna för begreppsanteckning; tangentbord när produktion/omfång kräver; skärmfria zoner vid djupläsning; retrieval/spacing i matte och SO/NO (LEARN).
Measure Closed-book exit tickets; andel lektionstid utan peer-visible multitasking; IFAU-liknande lokal uppföljning (inte bara tillgångssiffror).

Åk 7–9

Handling
Stop Facit-GenAI under practice; laptop-multitasking i synfält; betygssatta AI-uppgifter utan separat closed-book.
Start Device off body vid deep work (inte bara tyst); GenAI endast med guardrails (ledtrådar, inte lösning); explicit digital källträning separat från linjär djupläsning.
Measure Closed-book provandel; distraktionsfri minuter/dag; peer-spillover-proxy (skärmar synliga under genomgång: ja/nej).

Gymnasium

Handling
Stop Låta GenAI producera inlämning som sedan bedöms som lärande; ersätta productive struggle med sammanfattningsbottar.
Start Bastani-logik: practice med tutor-läge eller utan AI; bedömning utan verktyget som producerade läxan; high-information feedback (människa eller hybrid) på task/process — inte ego (FB).
Measure Delta practice-with-tool vs closed-book; metacognitive laziness-indikatorer (elev kan förklara utan chatten); sömn/skärm vid läggdags i elevhälsa (SLEEP) utan att annektera folkhälsobanken.

Gemensamt för alla stadier

  1. Inga färdiga lösningar från GenAI under practice.
  2. Deep work: enhet bort från kroppen, inte bara tyst läge (ATTN-003).
  3. Bedöm utan verktyget som producerade läxan.
  4. Förbud är nödvändiga, otillräckliga — mät encodingvillkor, inte policyetikett.
  5. Papper är medium, inte pedagogik — designad digital tutor kan vinna om closed-book håller.
